Executive verdict

Do not build “a screenshot app.” Build a local-first media workspace.

Shotbase wins the narrative around capture-after-capture: library, local AI, web capture, animated/3D treatment and sharing. CleanShot wins mature capture ergonomics, annotation depth, scrolling capture, recording overlays, OCR and Studio Mode. Znip can beat both by making the local workflow complete, making privacy visible, unifying stills and motion in one scene model, and pricing cloud separately.

Most important

Capture must feel instant

Every P0 feature is worthless if the overlay is slow, loses a recording, or asks for an account before copying a screenshot.

Strategic wedge

Private by construction

Local capture, OCR, search and AI are the default. Sharing is an explicit boundary with a visible destination.

Shotbase / the full public surface

Shotbase presents a five-stage workspace: Capture, Edit, Animate, Organize, Share. The implementation-level inventory is in docs/SHOTBASE_RESEARCH.md.

capture

Screen + web

Area, window, full screen, scrolling, full-page and viewport web capture, responsive breakpoints, light/dark modes.

animate

Motion with intent

Automatic zooms, cinematic 3D/perspective, text, shadow and effects, with a shared editor story.

organize

One visual library

Smart names, tags, summaries, search, reminders, tray history and local AI labelling.

private

Local AI

Shotbase claims naming, tagging and summarization happen locally on Apple silicon without remote image analysis.

CleanShot / the maturity benchmark

CleanShot's public all-features page exposes the deepest parity checklist: capture precision, annotation, recording overlays, Studio Mode, OCR, history, floating references and Cloud/team controls.

Capture and annotation

Area/window/full-screen/timer, scrolling in both directions, crosshair, magnifier, freeze screen, All-In-One mode, Quick Access Overlay, drag/drop, crop, secure pixelate, blur, arrows, spotlight, counter, pencil smoothing, highlighter, shapes, text styles, color picker, palettes, composition, backgrounds, auto-balance and editable projects.

Recording and Studio Mode

Video/GIF, selected area/window/full screen, system and microphone audio, camera bubble, click highlights, keystrokes, MP4/GIF/4K, smart zooms, cursor smoothing, cursor styling, motion blur, backgrounds, landscape/square/vertical exports and transcription.

Cloud and teams

One-click links, searchable content/transcripts/tags, expiry, password protection, comments, custom domain/branding, file access control, team management, SSO and SCIM.

Agentic IDE handoff

Read docs/ZNIP_FULL_CONTEXT.md first. Then read docs/FEATURE_MATRIX.md, docs/ARCHITECTURE.md, and docs/QA_ACCEPTANCE.md. Implement the smallest complete vertical slice for the current roadmap phase in Swift + SwiftUI/AppKit. Do not build a static prototype. Keep capture, editing, OCR, search and export local and offline-capable. Never upload capture content without an explicit share action. Add tests, permission-denied states, keyboard paths, VoiceOver labels, Reduce Motion behavior and recovery for every feature. Return files changed, tests run, known gaps and the next smallest vertical slice.

The canonical handoff also includes reviewer prompts, safety invariants, architecture modules, performance targets, pricing thesis and open questions.
