# Znip Competitive Intelligence

A source-backed, implementation-ready feature intelligence pack for **Znip (znip.app)**, a native macOS capture workspace intended to beat CleanShot X and Shotbase on capability, privacy, polish, and price.

> **Private research artifact — not a copy specification.** Use competitor behavior as a benchmark, then implement Znip's own interaction design, terminology, visual language, and code.

## Start here

1. Open `index.html` for the visual research dashboard.
2. Give an IDE `docs/ZNIP_FULL_CONTEXT.md` as the canonical zero-context handoff.
3. Use `docs/PRIORITY_ROADMAP.md` for sequencing.
4. Use `docs/FEATURE_MATRIX.md` as the complete capability inventory.
5. Use `docs/SHOTBASE_RESEARCH.md` and `docs/CLEANSHOT_RESEARCH.md` for evidence and competitor notes.

## Artifact map

- `docs/SHOTBASE_RESEARCH.md` — detailed public-surface research.

## Product thesis

Build the fastest, most private, most composable Mac capture workspace: instant capture, excellent annotation, studio-grade screen recording, scroll/web capture, a visual library, local AI, and optional sharing — with local-first defaults and a price that undercuts both competitors.

## Verification status

Research covers the public marketing sites, all-feature pages, pricing pages, privacy/terms pages, changelogs, FAQs, sitemap/download surfaces, and visible product claims available on 23 September 2026. Hidden app-only behavior, undocumented keyboard shortcuts, and paid-account features still require hands-on product testing.
